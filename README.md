🐍 Text Cobra

A simple, beginner-friendly Text Editor built using Python.

Text Cobra is a Python mini-project developed to practice programming fundamentals such as lists, strings, loops, functions, and modules. The project focuses on creating a simple text editing experience through which users can add, view, and remove text.

📌 About the Project

Text Cobra is a command-line-based text editor designed as a college mini-project.

The main objective of this project is to understand how basic Python concepts can be combined to build a practical application.

Instead of using advanced frameworks, the project focuses on implementing core functionality using Python fundamentals.

✨ Features
Add text to the editor.
View stored text.
Remove text line by line.
Simple and beginner-friendly interface.
Menu-driven interaction.
Practice with Python lists, strings, loops, and functions.

🚀 Getting Started
Prerequisites

Make sure Python is installed on your system.

You can check your Python installation using:

python --version


Installation

Clone the repository:

git clone https://github.com/kapil-goel952/Text_cobra.git

Navigate to the project directory:

cd Text_cobra

Run the Python program:

python main.py

Note: Replace main.py with the actual entry-point filename if your project uses a different name.
